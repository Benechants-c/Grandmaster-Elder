# 👑 Grandmaster Elder - Movie Maker

Make movies with your locked face. Same face, same age, same beard in every scene.

## Features
- 🔒 Character Lock - your face stays the same
- ✨ Generate Scene - Goma disaster, jungle, combat
- 🎬 Movie Merge - combine scenes
- ⏱️ Shortest scene = 30s
- 🗣️ Voice: Shona / English / Ndebele
- 📦 Export 1080p

## How to use
1. Open grandmaster-elder.html
2. Upload your photo and Lock Face
3. Generate Scene (min 30s)
4. Merge + Export
